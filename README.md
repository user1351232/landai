# 위치 기반 AI 토지 분석 플랫폼 (landai) v0.6

위치(위경도·주소·지도 클릭·내 위치)를 입력하면 필지를 찾아 검사하고, 지도와 분석 이력서로 보여주는 앱입니다.
전주시를 먼저 대상으로 하고, 완주군으로 확장합니다.

## 구성

| 폴더 | 내용 |
| --- | --- |
| `app/` | **앱 화면과 분석 로직** (윈도우·안드로이드 공용, 자바스크립트) |
| `src-tauri/` | 윈도우 앱 포장 (Tauri). 국내 공공 API 를 이 컴퓨터에서 직접 부르는 Rust 코드 포함 |
| `capacitor.config.json` | 안드로이드 앱 포장 (Capacitor) |
| `landai/` | 파이썬 엔진: 원본 자료 수신 검사, 필지번호 표준화, 이후 DEM 생성·AI 학습 |
| `app.py` | 파이썬 개발용 웹 화면 (국내 노트북에서만) |
| `docs/APP_BUILD.md` | **앱 빌드·다운로드 안내** |

## 왜 앱인가

브이월드는 해외 IP 요청을 막고, 지도 데이터를 해외 서버로 보내는 것은 공간정보 국외 반출 측면에서 조심해야 합니다.
앱은 사용자 기기(국내)에서 브이월드를 직접 부르므로 해외 서버를 거치지 않습니다.

## 앱 만들기

`docs/APP_BUILD.md` 를 따라 하면 GitHub 이 윈도우 설치 파일과 안드로이드 APK 를 자동으로 만들어 줍니다.

## 시험

```
npm test                                  # 앱 분석 로직 (JS)
python -m landai test                     # 파이썬 엔진
python tests_ui/ui_check.py <저장폴더>      # 앱 화면을 브라우저로 열어 흐름 시험 (playwright 필요)
```

## 개발용 실행 (국내 노트북, 선택)

### 윈도우 노트북

1. **Miniconda 설치**: https://docs.anaconda.com/miniconda/ 에서 윈도우용 설치 파일을 받아 기본값으로 설치합니다.
2. **압축 풀기**: `landai_v0.5.zip` 을 `문서` 폴더에 풉니다. `landai` 폴더가 생깁니다.
3. **설치**: `landai` 폴더의 `setup_windows.bat` 를 더블클릭합니다. 처음에는 5~15분 걸립니다.
4. **키 넣기**: `landai` 폴더의 `.env` 파일을 메모장으로 열어 키를 채우고 저장합니다.
   - `VWORLD_DOMAIN` 은 브이월드 키를 발급할 때 등록한 서비스 URL 과 똑같이 적습니다 (예: `http://localhost`).
5. **실행**: `run_windows.bat` 를 더블클릭하고 **1번(웹 화면 실행)** 을 고릅니다. 브라우저에 `http://localhost:8501` 이 열립니다.
   - 끌 때는 검은 창에서 `Ctrl + C` 를 누릅니다.

## (선택) 맥·리눅스에서 실행

```bash
cd landai
bash setup_mac_linux.sh     # 설치 (conda 가 있으면 conda, 없으면 .venv)
nano .env                   # 키 채우기
bash run_mac_linux.sh web   # 웹 화면 실행
```

## 웹 화면 사용법

1. 왼쪽에서 대상 지역(전주시·완주군)과 입력 방식(위경도·주소·지도 클릭)을 고릅니다.
2. 위치를 넣고 **분석하기** 를 누릅니다.
3. 오른쪽에 연결 확신도, 주소, 면적, 공시지가, 필지번호, 분석 이력서가 나옵니다.
4. **분석 이력서 내려받기** 로 실행 기록(JSON)을 저장할 수 있습니다.

분석 단계: 위치 확인 → 필지 조회(브이월드) → 필지번호 검사 → 위치 교차 확인 → 면적 계산(EPSG:5186) → 확신도 판정

## 문제가 생기면

| 증상 | 해결 |
| --- | --- |
| 지도가 회색으로 나옴 | 왼쪽 아래 배경지도를 OpenStreetMap 으로 바꾸기. 브이월드 키·등록 URL 확인 |
| "VWORLD_KEY 가 비어 있습니다" | `.env` 에 키를 넣고 저장했는지 확인한 뒤 웹 화면을 다시 실행 |
| "브이월드 오류 INCORRECT_KEY" 등 | 키 복사가 잘렸는지, `VWORLD_DOMAIN` 이 등록 URL 과 같은지 확인 |
| 설치 중 오류 | 검은 창의 메시지를 캡처해서 공유 |
| 그 밖에 | `run_windows.bat` → 2번(상태 점검) 결과를 캡처해서 공유 |

## 그 밖의 명령

```
python -m landai web                    웹 화면
python -m landai doctor                 설치·키·자료 상태 점검
python -m landai keys                   API 키 점검
python -m landai ingest --all           자료 수신 검사 (raw 폴더 자료)
python -m landai test                   테스트
```

## 자료 수신 검사 (개발용)

내려받은 원본 자료를 압축을 풀지 말고 `raw/` 아래 폴더에 넣고 `run_windows.bat` → 4번을 실행합니다. 결과는 `profiles/`(자료 프로필)와 `staging/quarantine/`(격리된 줄·필지번호)에 남습니다.

| 폴더 | 자료 |
| --- | --- |
| `raw/dong_code/` | 법정동코드 전체자료 |
| `raw/cadastral/` | 연속지적도 |
| `raw/permits/` | 개발행위허가 |
| `raw/topo5000/` | 1:5,000 수치지형도 도엽 |
| `raw/dem/` | DEM |

## 웹 배포

Streamlit Cloud 웹 배포는 사용하지 않습니다 (`docs/DEPLOY.md` 참고). 앱으로 배포합니다.

## 현재 한계

- 웹 화면과 공간 자료 검사는 개발 환경에 지도·지리 라이브러리가 없어 실제 화면으로는 확인하지 못했습니다. 브이월드 응답 처리와 분석 순서는 가짜 응답으로 시험했습니다 (테스트 26개 통과).
- 시도코드 45→52 변환과 전주시 시군구 코드(52111, 52113)는 법정동 대조표로 다시 확인해야 합니다.
- 규칙 목록은 `docs/rules.md` 에 있습니다.
