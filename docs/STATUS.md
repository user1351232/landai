## 검증한 것
- 파이썬 테스트 통과 (필지번호, 표 자료 검사, 브이월드 응답 처리, 분석 순서)
- 앱 JS 테스트 30개 통과 (필지번호, EPSG:5186 투영·면적을 타원체 값과 비교, 분석 순서, 브이월드 호출)
- 앱 화면을 Chromium 으로 열어 34개 흐름 시험 통과 (컴퓨터·휴대폰 화면 크기, 브이월드 응답은 흉내)
- 윈도우 앱의 허용 주소 검사(Rust) 단위 시험 통과
- 압축 파일에 키·`.env`·임시 파일이 들어 있지 않음
- 웹 구성 라이브러리의 파이썬 3.14 지원을 PyPI 에서 확인 (2026-10-12): streamlit, folium, streamlit-folium, pandas, pyyaml, python-dotenv, requests, shapely, pyproj, 그리고 주요 하위 라이브러리 numpy, pyarrow
